## Validación, modales y avisos (Fase 4)
- `PawLink.validate.check(campo, form)` / `.fields(form, ids)`: reglas reutilizables. Evento `pawlink:valid` en el `<form>` cuando todo es correcto (aquí el backend recogerá los datos).
- `PawLink.modal.confirm({title,text,ok,cancel,tone,onOk})` y `.notice({…})`: role="dialog" aria-modal, Esc, clic fuera, foco atrapado y devuelto.
- `PawLink.toast.show('Texto',{type:'ok|info|error'})` y `.flash('Texto')` (se muestra en la página siguiente).
- Contraseña: ≥10 caracteres, letra, número y símbolo. Teléfono: 9 cifras o con prefijo. NIF/NIE con letra de control. Fechas reales y sin futuro cuando procede.

## CSS
`assets/css/main.css` es solo un índice con `@import`; el orden es el de la cascada (no reordenar). Capas declaradas en main.css: `base, components, utilities, responsive`.

## JS (scripts clásicos, sin ES modules: funcionan con doble clic)
Cada página carga `core/boot.js` en el `<head>` y, al final del `<body>` con `defer`, `core/app.js`, `dom.js`, `storage.js` y solo los componentes que usa.
Un módulo se activa con `data-module="nombre"` en el elemento (varios separados por espacio) y se define con `PawLink.register('nombre', function (el) {…})`.

| Módulo | Elemento | Atributos |
|---|---|---|
| session | `<body>` | `[data-sw]`, `[data-login]`, `[data-logout]` en cualquier enlace/botón |
| nav-toggle | `.hd` | botón `.hd-burger`, `aria-controls="hd-nav hd-auth"`; estado `.is-open` |
| password-toggle | `<button>` tras el input | — |
| password-rules | `<input>` | requisitos `[data-r]` dentro de `.rc-pw` |
| match-check | `<input>` | `data-match-with`, `data-match-error` |
| char-counter | `<textarea>` | `data-counter`, `data-counter-max` |
| list-filter | `<input>` | `data-filter-items`, `data-filter-class`, `data-filter-attr`, `data-filter-empty` |
| reveal | `<button>` | `data-hide`, `data-show`, `data-check`, `data-check-value` |
| form-validator | `<form novalidate>` | reglas en cada campo: `data-v="required email name tel url cif nif password money date:past num:1:500 min:N max:N match:id optional"`; mensajes `data-msg`; destino `data-success-href`, `data-success-message` |
| confirm-action | enlace o botón | `data-confirm`, `data-confirm-title`, `data-confirm-ok`, `data-confirm-tone="danger"`, `data-confirm-message` (modal de confirmación) |
| go-back | `<button>` | vuelve atrás; si no hay historial, `data-back-href` |
| notify | `<button>` | `data-notify`, `data-notify-type` (aviso/toast) |
| proto-form | `<form>` | formularios sin reglas: evita el envío (sin backend) |

| (controlador) pawmate-controller | páginas PawMate | `data-pm`, `data-pm-amount`, `data-pm-freq`, `data-pm-reset` |
